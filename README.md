Warhammer 40,000: 11th Edition - custom updates
==============================

## Overview ##

__What's this?__

This is a fork of BSData's great work, just to add some custom tweaks / be able to update points / rules after a balance dataslate. This fork isn't maintained on production level, just for my own personal use. If you want regular correct and on time updates you shouldn't use this fork, but choose the original Repo instead.

__Original description__

BSData organisation created this project. It's a GitHub repository of datafiles.
Maintained by community, in no way endorsed by any company/publisher.
